📐 Actuarial Mathematics & Loss Function Specification
Formal Algorithmic Formulations
1. Gradient Boosting Classifier Deviance Loss
L(y, F(x)) = - \sum_{i=1}^{N} [y_i \ln(p(x_i)) + (1 - y_i) \ln(1 - p(x_i))], \quad \text{where } p(x) = \frac{1}{1 + e^{-F(x)}}
Sequential additive tree boosting fits decision trees to the negative gradient of the binomial log-likelihood (pseudo-residuals). A shrinkage learning rate η = 0.07 and subsampling ratio of 0.85 prevent overfitting on imbalanced employee data.
2. Random Forest Gini Impurity & Bagging Formulation
I_G(t) = 1 - \sum_{i=1}^{C} p(i|t)^2 = 1 - (p_{\text{exit}}^2 + p_{\text{retain}}^2)
Bootstrap aggregation (bagging) builds 160 decorrelated decision trees sampled with replacement. Feature sub-sampling at each split (√M) mitigates single-feature dominance and yields reliable out-of-bag error estimates.
3. Multi-Layer Perceptron (MLP) Neural Network Optimization
L(W, b) = - 1/N ∑ [y_i log(ŷ_i) + (1 - y_i)log(1 - ŷ_i)] + (α/2) ||W||_2^2
Architecture consists of dense hidden layers (64 → 32 → 1) with ReLU non-linear activations f(z) = max(0, z). Optimization utilizes the Adam solver with momentum and L2 regularization penalty α = 0.01 to ensure numerical stability.
4. Support Vector Machine (SVM) Soft-Margin & RBF Kernel
min 1/2 ||w||^2 + C ∑ ξ_i s.t. y_i(w^T φ(x_i) + b) ≥ 1 - ξ_i, K(x, x') = exp(-γ ||x - x'||^2)
Maximizes margin separation in infinite-dimensional Hilbert space via the Radial Basis Function (RBF) kernel trick. Regularization hyperparameter C = 1.8 penalizes classification slack variables ξ_i.
5. K-Means Unsupervised Objective (WCSS Minimization)
J = ∑_{k=1}^K ∑_{x ∈ S_k} ||x - μ_k||^2, where μ_k = (1 / |S_k|) ∑_{x ∈ S_k} x
Minimizes within-cluster sum of squares over normalized feature dimensions to discover intrinsic employee risk cohorts without utilizing supervision labels.
